Documentation Characters

ข้อมูลตัวละคร

เซิร์ฟเวอร์จะพยายามโหลดข้อมูลตัวละครจาก HSR-API เมื่อเริ่มทำงาน:

  • API หลัก: hsr-api.vercel.app/api/v1/characters จาก ajcastan0103/HSR-API
  • เซิร์ฟเวอร์แปลงข้อมูลที่ได้รับเป็น ID, ชื่อ, ระดับดาว, สาย (Path), ธาตุ (Element) และ URL รูปภาพ ก่อนเก็บไว้ในหน่วยความจำเพื่อให้หน้าเว็บเรียกใช้
  • หากเรียก API ไม่สำเร็จ จะใช้ข้อมูลสำรองจาก characters.json ที่อยู่ในโฟลเดอร์หลักของโปรเจกต์

รูปภาพตัวละคร

หน้า Characters ใช้ URL รูปภาพที่มากับข้อมูลตัวละครจาก API (ช่อง img) หรือจาก characters.json เมื่อใช้ข้อมูลสำรอง รูปภาพจึงอาจถูกโหลดจากเซิร์ฟเวอร์ภายนอกตาม URL ของแต่ละรายการ

ข้อมูลคิวและประวัติ

คิวจัดทีมและประวัติการเพิ่ม/เลือกตัวละครไม่ได้ดึงจาก API ภายนอก แต่สร้างและเก็บไว้ในหน่วยความจำของเซิร์ฟเวอร์ขณะทำงาน ข้อมูลเหล่านี้จะเริ่มใหม่เมื่อเซิร์ฟเวอร์ปิดหรือเริ่มทำงานอีกครั้ง

  • /watchlist อ่านคิว, POST /watchlist เพิ่มตัวละคร และ DELETE /watchlist/process นำตัวละครออกจากคิว
  • /history อ่านประวัติ และ POST /undo ย้อนการกระทำล่าสุด
  • /characters?sort=selection อ่านรายการตัวละครที่เรียงแล้ว โดยเลือกอัลกอริทึมได้เป็น selection, insertion หรือ bubble
